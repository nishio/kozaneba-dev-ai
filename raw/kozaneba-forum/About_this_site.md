About this site
A public forum to discuss [Kozaneba].
	Feature Requests
	Bug Reports
	Questions
	and more!

You can use your real name, handle name, or even anonymously.
	There is no obligation to mention your organization's name.

[[Join the forum]]
	[Invitation Link https://scrapbox.io/projects/kozaneba-forum/invitations/7e80c7198f5739df098101b2a2b5041d]

Questions, requests and bug reports
	Please create a new page and write [request], [bug], etc.
	Completed requests will be marked with a [done.icon] icon.
	Feel free to write anything without worrying about mistakes [nishio.icon].

[[[Release Notes]]]
	You can check the latest release status.

[[How to use Scrapbox]]
	For more information on how to use Scrapbox, please visit [/help].

[[How to use Kozaneba]]
	There is a tutorial when you start, so you can learn it there.
		In past user tests, it took 15 minutes to learn the basic usage.
			The content has increased a bit since the test, but I think 30 minutes is enough.
		To improve this learning process, we are looking for people who can help with the user test.

	I'm also planning to create a [help] document on this page.
